# اجرای آمادهٔ ویندوز

`FallenSignal-Windows-x64.zip` نسخهٔ native ویندوزی بازی است. برای اجرای آن به مرورگر، CMake، Visual Studio یا هیچ game engineای نیاز نیست.

1. فایل ZIP را extract کن.
2. `FallenSignal.exe` را اجرا کن.

نیازمندی: Windows 10/11 نسخهٔ 64 بیتی و درایور گرافیک با پشتیبانی OpenGL 3.3 یا بالاتر.

این build هیچ عکس یا texture خارجی برای فرشته‌ها ندارد؛ هر فرشته از هندسهٔ سه‌بعدی procedural با بدن حجمی، پرهای جداگانه و برجستگیِ quill ساخته می‌شود، دوربین زیرِ بال‌ها قرار می‌گیرد و توپ گلوله‌های قرمز بالستیک شلیک می‌کند. بازی در حالت تمام‌صفحهٔ native اجرا می‌شود و یک سیگنالِ حدوداً ۱۵۰ متری را در یک مسیر glide کوتاه داخل محور اپتیک نگه می‌دارد. SHA-256 فایل در `SHA256SUMS.txt` آمده است.
